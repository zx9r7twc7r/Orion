Integration notes for this project
----------------------------------
* Compiled as GLSL via SharcGlslHelpers.h (define SHARC_ENABLE_GLSL before
  including it). The helpers express "RWStructuredBuffer_*" as
  GL_EXT_buffer_reference types, so any pass that includes these headers
  must declare GL_EXT_buffer_reference (plus, per the helper header, the
  explicit-arithmetic-types int64/float16, 16-bit storage and
  control-flow-attributes extensions).
* The three cache buffers are reached through 64-bit buffer device
  addresses passed in the camera UBO; verify the device has
  bufferDeviceAddress enabled (this renderer already uses it for the
  Section BLAS scratch buffers).
* Required shader compiler support was verified on this project's toolchain
  (Vulkan SDK 1.4.309.0 glslangValidator, --target-env vulkan1.4).
